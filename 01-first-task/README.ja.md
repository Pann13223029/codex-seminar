# 01：最初の作業

時間：約5分。目標：エージェントがチャットボットとどう違うかを知ります。
そして、エージェントの変更を確認し、元に戻す方法を覚えます。

## 1. Codexに作業の材料を渡す

ワークショップ用のフォルダで、次をコピーして貼り付けます：

```text
notes.md というファイルを作り、架空のゼミのミーティング記録を5つ書いてください。それぞれに、日付、箇条書き3つ、やること（アクション）1つを入れてください。そのあと、何を作ったかを教えてください。
```

Codexは、あなたのフォルダに本物のファイルを書きます。ファイルを開いて
確認するか、Codexに頼みます：`notes.md を見せてください。`

> **Gitがない場合：** 手順2と5は飛ばします。手順4では、何を変えたかを
> Codexに聞いてください。

## 2. スナップショットを保存する

スナップショット（Git）を保存しておくと、このあとCodexが変えた内容を
正確に見られます。元に戻すこともできます。Gitが必要です
（[ステップ00](../00-install/README.ja.md#recommended-install-git)を見てください）。

```text
このフォルダがまだGitリポジトリでなければ、Gitリポジトリにしてください。そして、すべてのファイルのスナップショットを "notes created" というメッセージで保存してください。
```

Codexが、先に許可を求めることがあります。スナップショット用のフォルダ
（`.git`）は保護されているからです。内容を読んでから、許可してください。

Codexが、Gitにはあなたの名前が必要だと言ったら（"Please tell me who you
are"）、次を貼り付けます：
`このフォルダだけで、Gitの名前を [名前]、メールアドレスを [メールアドレス] に設定してください。そのあと、もう一度スナップショットを保存してください。`

## 3. ファイルの変更を頼む

```text
notes.md を書き直して、すべてのやること（アクション）を一番上の表にまとめてください。表の列は Date、Action、Owner にしてください。元の記録は、表の下に残してください。
```

## 4. 変更を確認する

何が変わったかを見ます。スナップショットを保存したので、アプリの
レビュー画面で、追加された行と削除された行を見られます。いちばん簡単
なのは、こう頼む方法です：
`前回のスナップショットから何が変わったかを、正確に見せてください。`

自分に問いかけてください。これは自分が頼んだ内容か？ 頼んでいない
ところまで変えていないか？

## 5. 元に戻す

```text
notes.md への最後の変更を、前回のスナップショットから復元して元に戻してください。そのあと、スナップショットと同じになっているか確認してください。
```

そのあと、ファイルを開いて、自分で確かめてください。

## いま起きたこと

| チャットボット | エージェント（Codex） |
| --- | --- |
| チャットの中で答える | あなたのフォルダのファイルを読み、書き、実行する |
| 結果を自分でコピーして持ち出す | 結果は、作業している場所に保存される |
| 何を変えたか忘れやすい | すべての変更を確認して、元に戻せる |

## 初日からの3つの習慣

1. **1つのプロジェクトに1つのフォルダ。** Codexは、そのフォルダしか
   見ません。
2. **受け入れる前に読む。** フォルダの中身に責任を持つのは、あなたです。
3. **思い込まずに聞く。** Codexが何をしたかわからないときは、聞いて
   ください：
   `具体的に何を変えましたか？ また、それはなぜですか？`

手順1から5は短いので、1つのチャットで大丈夫です。次のガイドでは、
**New chat**（新しいチャット）を始めてください。長いチャットは、利用枠を
多く使います。
