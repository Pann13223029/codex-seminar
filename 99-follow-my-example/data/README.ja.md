# データ

`incinerators_fy2005_fy2024.csv`：市町村のごみ焼却施設のレコード2,332件です。年度は2005年度（1,318件）と2024年度（1,014件）です。

**出典：** 環境省「一般廃棄物処理実態調査」の施設別データ（Excel ファイル）。e-Stat
（https://www.e-stat.go.jp/）で公開されています。e-Stat のコンテンツは、出典を示せば再利用・加工ができます。利用条件は、クリエイティブ・コモンズ 表示 4.0 と両立するものです。

**加工：** 立命館アジア太平洋大学の Pann Phetra の卒業論文のために、データを読み取り、重複を取り除きました。公式の施設コードは年によって変わっていますが、`facility_id` を使うと同じ施設を年をまたいでつなげられます。このワークショップで使う列だけを残し、列名は英語にしています。列の意味は `../AGENTS.md` にあります。

注意：2024年度の調査では、発電設備のない施設のほとんどで、発電の項目が空欄になっています。一方、2005年度では0と記録されています。空欄は0として扱ってください。
