# 解答例

自分の結果が出てから開いてください。数字はすべて `AGENTS.md` の定義を使っています
（発電の値の空欄はゼロとして扱います）。私の論文の分析と一致します。

## ステップ2：行数

| 年度 | レコード（1行）の数 |
| --- | --: |
| 2005 | 1,318 |
| 2024 | 1,014 |

## ステップ2：3つの割合

| 指標 | 2005年度 | 2024年度 |
| --- | --: | --: |
| 発電設備があるレコード（power_capacity_kw > 0） | 21.6%（1,318件中285件） | **41.1%**（1,014件中417件） |
| 発電しているレコードで燃やしたごみの量（power_generated_mwh > 0 のレコードの throughput） | 60.5% | **80.1%** |
| 発電設備があるレコードの処理能力（設計値） | 56.0% | **70.5%** |

つまり、答えは「はい」です。発電設備がある**施設**は10施設中およそ4施設ですが、
**ごみの量（トン）**で見ると、10トン中およそ8トンが発電している施設で燃やされています。
発電しているのは大きな施設なので、施設の数で数えると、カバー率を実際より小さく見てしまいます。

## ステップ2：欠損値のわな

2024年度では、`power_capacity_kw` が空欄のレコードが **595** 件、ゼロが2件、
正の値が417件です。2005年度には空欄がありません。発電設備のない施設は0と
記録されていました。報告の形式が変わったのです。

| 空欄の扱い方 | 2024年度の発電設備がある割合 |
| --- | --: |
| 空欄 = ゼロ（ここではこれが正しい） | 41.1%（1,014件中417件） |
| 空欄を除く | 99.5%（419件中417件） |

最初の割合が99.5% になったなら、これが理由です。同じ質問でも、空欄の扱い方の
ルールが違うと、まったく違う答えになります。欠損値をどう扱ったかを、
いつも確かめてください。

定義の確認をもう1つ。**発電設備がある**レコードではなく、**発電している**
レコード（power_generated_mwh > 0）を数えると、2024年度は40.4%
（1,014件中410件）になります。近いですが、同じものではありません。

## 追加課題：同じ施設どうしで比べる

両方の年に出てくる施設は732施設です。

| グループ | 発電設備がある割合 |
| --- | --: |
| 同じ732施設、2005年度 | 29.9% |
| 同じ732施設、2024年度 | 32.1% |
| 2005年度のレコードにだけある施設 | 11.3% |
| 2024年度のレコードにだけある施設 | 64.5% |

**すべてのレコード**で見ると、割合はおよそ20ポイント上がりました。しかし、
**同じ施設**どうしで見ると、およそ2ポイントしか上がっていません。上がった分の
ほとんどは、発電設備のない小さな施設がレコードから消え、発電設備のある大きな施設が
新しく加わったことによるものです。データからわかるのはレコードだけで、施設が
なぜできたのか、なぜなくなったのかはわかりません。そのため、これは小さな
ごみ焼却施設をまとめるという日本の政策と「矛盾しない」とは言えますが、
政策が原因だという証拠にはなりません。
