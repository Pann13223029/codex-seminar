# 03：確認と申告

Codexは速く、たいていは正しいです。だからこそ、間違いを見落としやすくなります。提出するものには、あなたの名前が入ります。だから、確認するのはあなたの仕事です。

## チェックリスト

結果を使う前に：

- [ ] **数字を2つ、手で計算し直す。** データをExcelかGoogle スプレッドシートで開き、フィルターをかけ、数え、割り算します。数字は一致しますか？
- [ ] **定義を確認する。** 正確には何を数えたのでしょうか？（「発電設備がある」は、設備の容量が0より大きいという意味にも、発電した電力量が0より大きいという意味にもなります。この2つでは答えが変わります。）
- [ ] **欠損値を確認する。** 空欄は0として扱われたのか、除かれたのか、そのまま残されたのか。こう聞きましょう：`欠損値をどう扱いましたか？別の扱い方をしたら、結果はどう変わりますか？`
- [ ] **何が間違っていそうかを聞く。**
      `この結果が間違っている可能性を3つ挙げて、いちばんありそうなものを確かめてください。`
- [ ] **参考文献はすべて自分で確認する。** 1つずつ検索します。AIは、本物に見える参考文献をでっち上げることがあります。
- [ ] **提出する文はすべて読む。** 自分の言葉で説明できない文があれば、書き直すか削除します。

## あなたの仕事として残ること

- **あなたの判断。** 研究の問い、どの結果が大事か、それが何を意味するかは、あなたが決めることです。
- **確認していない事実。** Codexは、古い情報や間違った情報を記憶から述べることがあります。出典を聞いて、自分で見てください。
- **個人的な情報や利用が制限されたデータ。** READMEのプライバシーの注意を見てください。

## 申告する

AIの助けを申告しないと、大学の規則（APUを含む）では盗用とみなされることがあります。授業や指導教員のルールを確認してから、AIが何をして、あなたが何をしたかを、はっきり書きましょう。テンプレート（論文を書く言語に合わせて選んでください）：

**日本語**

```text
本[論文/レポート]の作成にあたり、筆者は[OpenAI Codex]を[分析コードの作成と実行 / メモの整理 / 文章の校正 / X章の一部の下書き]に使用した。分析の設計、データと結果の確認、AIの支援を受けたすべての部分の確認と修正は筆者が行い、内容についての責任はすべて筆者が負う。
```

**English**

```text
During the preparation of this [thesis/report], the author used [OpenAI Codex] for [writing and running analysis code / organizing notes / language revision / drafting parts of section X]. The author designed the analysis, checked the data and results, reviewed and edited all AI-assisted material, and takes full responsibility for the content.
```

Codexに下書きしてもらい、それが事実どおりになるように自分で直すこともできます。Codexは、あなたがチャットの外で何を確認したかを見ることができません。だから、それを伝えてください：

```text
このプロジェクトで私たちがしたことを見てください（outputs/ai-log.mdがあれば使ってください）。あなたがしたことと私がしたことを述べる、2文のAI利用の申告文を[日本語/英語]で下書きしてください。私が自分で確認したのは次のことです：[手で確認したこと。例：「主な割合をスプレッドシートで確認した」]。どちらの部分も大げさに書かないでください。
```
