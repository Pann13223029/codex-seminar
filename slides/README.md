# Slides

Three ways to view the deck. Pick whichever works on your device.

| Option | How | Best for |
| --- | --- | --- |
| **PDF** | Open [codex-for-research.pdf](codex-for-research.pdf). GitHub shows it in the browser; you can also download it. | Phones, reading on any device, printing |
| **Web page** | Open https://pann13223029.github.io/codex-seminar/slides/ | The live version with animations; use the arrow keys, **F** for full screen |
| **HTML file** | Download [index.html](index.html) and double-click it, or open it from any web browser | Presenting offline |
