# Brief templates

An `AGENTS.md` brief tells Codex what your project is and the rules it must
follow ([step 02](../02-your-project/)). These are starting points; Codex
fills them in by interviewing you.

| Template | Use it for |
| --- | --- |
| [`AGENTS.md`](AGENTS.md) | Any seminar project: data, notes, drafts |
| [`AGENTS-survey.md`](AGENTS-survey.md) | A real survey export, with personal-data and quote rules |

Both include the rule that Codex adds one line to `outputs/ai-log.md` after
each task. Step 03 uses that log to write your AI-use statement.

**Use one.** Open your project folder in Codex and paste (change the path to
where your copy of `codex-seminar-main` is):

```text
Copy the file [path to codex-seminar-main]/templates/AGENTS-survey.md into this folder as AGENTS.md. Then look at my files and ask me questions one at a time to fill in every part in [square brackets]; do not fill any part in yourself. Keep the Rules section as it is unless I ask to change it. Show me the finished file.
```

Codex asks permission to read a file outside your folder. Approve it.
