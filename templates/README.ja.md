# 指示書のテンプレート

指示書 `AGENTS.md` は、プロジェクトの内容と守るべきルールをCodexに伝えるファイルです
（[ステップ02](../02-your-project/README.ja.md)）。ここにあるのは、そのたたき台です。
Codexがあなたに質問しながら埋めていきます。

| テンプレート | 使う場面 |
| --- | --- |
| [`AGENTS.md`](AGENTS.md) | ゼミのプロジェクト全般（データ、メモ、下書き） |
| [`AGENTS-survey.md`](AGENTS-survey.md) | 本物のアンケートの書き出しデータ（個人情報と引用のルール付き） |

どちらにも、作業のたびに `outputs/ai-log.md` に1行書き足すルールが入っています。
ステップ03では、この記録を使ってAI利用の申告文を書きます。

**使い方。** Codexで自分のプロジェクトのフォルダを開き、次を貼り付けます
（パスは、手元の `codex-seminar-main` の場所に変えてください）：

```text
[codex-seminar-main の場所]/templates/AGENTS-survey.md を、このフォルダに AGENTS.md としてコピーしてください。そのあと私のファイルを見て、[角かっこ] の部分をすべて埋めるために、質問を1つずつしてください。自分で埋めないでください。私が頼まない限り、Rules の部分はそのままにしてください。最後に、できあがったファイルを見せてください。
```

フォルダの外のファイルを読むので、Codexが許可を求めてきます。許可してください。
