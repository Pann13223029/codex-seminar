# このワークショップのためのパソコンの基本

ガイドでは、毎日の基本的な操作はできるものとして進めます。その操作を短く
説明します。自分のパソコン（MacかWindows）を選んでください。

<a id="unzip-the-downloaded-repository"></a>
## ダウンロードしたリポジトリを解凍する

- **Mac：** ダウンロードフォルダの `codex-seminar-main.zip` をダブル
  クリックします。すぐ横に `codex-seminar-main` フォルダができます。
- **Windows：** `codex-seminar-main.zip` を右クリック → **すべて展開** →
  **展開** を選びます。Windowsでは、フォルダの中にもう1つフォルダが
  できることがよくあります：`codex-seminar-main\codex-seminar-main`。
  内側のフォルダを開いてください。`README.md` が入っているのは、
  そちらです。

## 隠しフォルダ（`.agents` など）を表示する

名前がドット（.）で始まるフォルダは、隠れています。開く必要はありません。
見たいときは、次のようにします：

- **Mac（Finder）：** `⌘ ⇧ .`（Command・Shift・ピリオド）を押すと、
  隠しファイルが表示されます。もう一度押すと隠れます。
- **Windows（エクスプローラー）：** **表示 → 表示 → 隠しファイル**。

<a id="open-a-csv-file-in-a-spreadsheet"></a>
## CSVファイルを表計算ソフトで開く

- **Excel（WindowsまたはMac）：** Excelを開いてから、**ファイル → 開く**
  で `.csv` ファイルを選びます。（ダブルクリックすると、別のアプリで開く
  ことがあります。）
- **Google スプレッドシート：** 空白のシートを開き、**ファイル →
  インポート → アップロード** でファイルを選んで、**現在のシートを置換する**
  を選びます。
- **Mac の Numbers** でも開けます。ただし、このあとの手順はExcelか
  Google スプレッドシートを使います。

<a id="count-rows-without-filters-use-a-formula"></a>
## フィルターを使わずに行を数える：数式を使う

数字を手で確認するいちばん簡単な方法は、`COUNTIFS` の数式です。データの
右側の空いているセルをクリックして、数式を入力し、Enterを押します。
ExcelでもGoogle スプレッドシートでも、同じように使えます。

**コース99**（ごみ焼却施設のデータ：A列は `fiscal_year`、H列は
`power_capacity_kw`）：

| 内容 | 数式 | 正しい値 |
| --- | --- | --: |
| 2024年度（FY2024）のレコード | `=COUNTIF(A:A,2024)` | 1014 |
| 2024年度（FY2024）のレコードのうち、発電設備があるもの | `=COUNTIFS(A:A,2024,H:H,">0")` | 417 |
| 割合 | `=COUNTIFS(A:A,2024,H:H,">0")/COUNTIF(A:A,2024)` | 0.411 (41.1%) |

**コース98**（アンケート：E列は「Where are you visiting from?」（どこから
来ましたか）、K列は「Information available in my language」（自分の言語で
情報が得られる））：

| 内容 | 数式 | 正しい値 |
| --- | --- | --: |
| 国内からの回答 | `=COUNTIF(E:E,"Japan*")` | 60 |
| 国内からの回答のうち、4か5をつけたもの | `=COUNTIFS(E:E,"Japan*",K:K,">=4")` | 51 |
| 割合 | `=COUNTIFS(E:E,"Japan*",K:K,">=4")/COUNTIF(E:E,"Japan*")` | 0.85 (85%) |

`"Japan*"` は「Japanで始まる」という意味です。`">0"` は「0より大きい」
という意味です。空欄のセルは数に入りません。

## フィルターで行を数える（もう1つの方法）

- **Excel：** データの中のどれかのセルをクリックし、**データ → フィルター**
  を選びます。列見出しの矢印をクリックし、**数値フィルター → 指定の値より
  大きい**（または **テキスト フィルター → 指定の値で始まる**）を選びます。
  表示されている行の数が、左下に出ます（「y レコード中 x 個が見つかり
  ました」）。
- **Google スプレッドシート：** **データ → フィルタを作成** を選び、列見出し
  のフィルタアイコンをクリック → **条件でフィルタ**。列を選ぶと、右下に
  件数（**Count**）が出ます。

## ターミナルを開く（任意のCodex CLIを使うときだけ）

- **Mac：** `⌘ Space` を押し、**Terminal**（ターミナル）と入力して、Enterを
  押します。
- **Windows：** Windowsキーを押し、**PowerShell** と入力して、Enterを
  押します。

このワークショップでは、ほかにターミナルを使う場面はありません。
