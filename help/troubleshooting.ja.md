# うまくいかないとき

下から自分の問題を探してください。たいていは、プロンプト1つか再起動1回で直ります。
解凍・隠しフォルダ・スプレッドシートについては[パソコンの基本](computer-basics.ja.md)を見てください。

## アプリに Codex がない

無料のアカウントには、まだ Codex が使えないものがあります
（[料金](https://learn.chatgpt.com/docs/pricing)）。ChatGPT のデスクトップアプリを
更新し、サインアウトしてもう一度サインインしてから、確認してください。それでもない場合は、
今日は隣の人と一緒に進めます。隣の人の画面で全部のステップを見て、あとで自分でくり返せます。

## 途中で利用枠を使い切った

ファイルは消えていません。Codex が保存したものは、すべてフォルダに残っています。
利用枠が回復したら（いつ回復するかはアプリに表示されます）、同じフォルダを開いて
**New chat** を始め、次を貼り付けます：

```text
AGENTS.md を読み、outputs/ と scripts/ の中のファイルを見てください。私がガイドのどのステップまで終えたか、次は何をすればよいかを教えてください。ファイルは何も変えないでください。
```

それまでは隣の人と一緒に進めます。次に利用枠を節約するには、
[利用枠を長持ちさせる](../prompt-guide/README.ja.md#make-your-usage-last)を見てください。

## Codex に「できません」と言われた

Codex は、保護されたフォルダ（`.git`、`.agents`）に書くとき、フォルダの外に書くとき、
インターネットを使うときに、先に許可を求めます。許可を求めずに「できません」と言った場合は、
こう返事をします：`許可を求めてから、もう一度やってください。`

## スキルが一覧に出てこない

ChatGPT アプリをいったん閉じて開き直し、メッセージ欄に `$` と入力します。
それでも出てこない場合は、インストールされていません。
[04 のパートA](../04-make-a-skill/README.ja.md#part-a-install-the-example-skills-5-minutes)
をもう一度行い、許可のお願いを承認してください。

## 「python が見つかりません」と出る（Windows）

- [python.org/downloads](https://www.python.org/downloads/) から Python を
  インストールします。最初の画面で **「Add python.exe to PATH」** にチェックを入れます。
- `python` と打つと Microsoft Store が開く場合は、**設定 → アプリ → アプリの詳細設定 →
  アプリ実行エイリアス** を開き、**python** の2つの項目をオフにします。
- ChatGPT アプリを閉じて開き直し、もう一度試します。

## pandas を入れるときに「externally-managed-environment」と出る（Mac）

お使いの Python では、パソコン全体に追加の部品を入れることができません。
このプロジェクト専用の環境を作るよう Codex に頼みます：

```text
このフォルダに .venv という仮想環境を作り、そこに pandas、matplotlib、openpyxl をインストールして、このプロジェクトのスクリプトではいつもそれを使ってください。先に私に許可を求めてください。
```

## Git や Python を入れたのに、Codex が見つけられない

ChatGPT アプリを完全に終了して、開き直します。アプリは、起動する前に入っていた
プログラムしか見つけられません。

## グラフの日本語が四角（□）になる

グラフのフォントに日本語の文字がありません。次を貼り付けます：

```text
日本語が表示できるフォントでグラフを作り直してください。Mac では Hiragino Sans、Windows では Yu Gothic か Meiryo を使ってください。四角（□）になっているラベルがないか確認してください。
```

## Excel のファイルが開けない

`.xlsx` ファイルを読むには、部品がもう1つ必要です。次を貼り付けます：
`Excel のファイルを読めるように、私のユーザーアカウントに openpyxl をインストールしてください。先に私に許可を求めてください。`

## 解凍したら、フォルダの中に同じ名前のフォルダがある（Windows）

Windows では `codex-seminar-main\codex-seminar-main` になることがあります。
内側のフォルダ（`README.md` が入っている方）を開いてください。

## `.md` ファイルはどう開くの？

`.md` ファイル（Markdown）は、ただのテキストです。テキストエディット（Mac）か
メモ帳（Windows）で開けます。Codex に頼むこともできます：`outputs/findings.md を見せてください。`

## Codex が、望んでいない変更をした

スナップショットを保存していれば、こう頼みます：`最後の変更を元に戻して、何を戻したかを見せてください。`
スナップショットのしくみは[ステップ01](../01-first-task/README.ja.md)を見てください。
